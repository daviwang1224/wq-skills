## 环境要点：Git 推送需走本地代理
- 远程 origin 为 SSH `git@github.com:daviwang1224/wq-skills.git`，但当前网络下 22/443 SSH 端口均超时，环境默认 HTTP 代理 `127.0.0.1:59878` 返回 502。
- 本地可用代理为 `127.0.0.1:7897`（HTTP/SOCKS 均可）。推送方法：
  `env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY -u all_proxy -u ALL_PROXY HTTPS_PROXY=http://127.0.0.1:7897 HTTP_PROXY=http://127.0.0.1:7897 git push https://github.com/daviwang1224/wq-skills.git main:main`
  （必须清理残留代理变量，否则仍走 59878 报 502；远程 URL 用 HTTPS 而非 SSH。）
- 用显式 URL 推送后 origin/main 跟踪引用不会自动更新，需 `git fetch <https-url> main` 再 `git update-ref refs/remotes/origin/main FETCH_HEAD` 对齐。
